# Development log - 2026-06

## 2026-06-06 - Native CLI ownership replaced legacy shell implementations

### Result

- Version 2.4.0 delegated Docker, plugin, OpenCode, process, and changed-file
  operations to released nils-cli binaries while retaining shell aliases and
  compatibility glue.

### Why / context

- The repository should own interactive Zsh integration, not duplicate durable
  command implementations already tested and released by nils-cli.

### Evidence

- The v2.4.0 changelog enumerates the ownership moves, and the preceding
  archive work preserved retired implementations without allowing generated
  wrappers to shadow native binaries.

### Links

- <https://github.com/sympoies/zsh-kit/releases/tag/v2.4.0>
- [Legacy archive](../../archive/legacy-zsh-cli-tools/README.md)

## 2026-06-04 - Agent-friendly bootstrap shipped in v2.3.0

### Result

- Added a setup dispatcher that previews changes first, avoids installing tools
  by default, and can run a destination smoke check after bootstrap.

### Why / context

- A shell takeover is environment-sensitive; safe automation needs a
  dry-run-first boundary and separate decisions for shell wiring and package
  installation.

### Evidence

- The v2.3.0 release also extracted the detailed setup guide and hardened the
  Starship Codex prompt gate.

- <https://github.com/sympoies/zsh-kit/releases/tag/v2.3.0>
