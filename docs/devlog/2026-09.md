# Development log - 2026-09

## 2026-09-27 - Keep Linux mitmproxy in the apt-only manifest

### Result

- Restored mitmproxy to the Linux apt-only optional list. Linuxbrew resolves the
  same name to a macOS-only cask, so it cannot install the tool on Linux.

### Why / context

- The earlier manifest move below was based on the package name being present in
  Homebrew, but the actual Linux install selected an unsupported cask. Ubuntu's
  apt package is the working Linux route.

### Evidence

- The test-first regression check reproduced the incorrect manifest placement;
  apt installation succeeded on both affected Ubuntu hosts.

## 2026-09-27 - Route Linux mitmproxy through Homebrew

### Result

- Moved mitmproxy from the Linux apt-only optional list into the Linux Homebrew
  optional list, so install-tools --all can install it on Linuxbrew hosts.

### Why / context

- The installer reads the Homebrew manifests but does not consume apt-only
  manifests; keeping a formula available to Linuxbrew in the apt-only list left
  new Linux hosts without the declared tool.

### Evidence

- The regression test failed before the manifest change and passed after it;
  ./tools/check.zsh and ./tests/run.zsh passed.

## 2026-09-27 - Linux tool install reads every manifest entry

### Result

- The installer now processes final rows without newlines and isolates Homebrew
  from manifest stdin, the Linux tool list has a proper final newline, and
  required tools no longer repeat in the optional list. The required list now
  includes GnuPG for signed Git commits; the optional list includes rumdl and
  ShellCheck for repository checks.

### Why / context

- An unterminated Linux-only libnotify row was skipped, while a package-manager
  child could consume subsequent manifest rows. This made new-host installs
  silently incomplete or require retries.

### Evidence

- `zsh -f tests/install-tools.test.zsh`; `zsh -f ./tools/check.zsh`;
  `zsh -f ./tests/run.zsh`; `bash ./scripts/ci/markdownlint-audit.sh --strict`;
  `devlog check`; `git diff --check`.
