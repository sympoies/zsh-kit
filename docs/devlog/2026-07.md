# Development log - 2026-07

## 2026-07-14 - Private overlay became symlink-safe

### Result

- The public loader gained support for an externally owned symlinked overlay
  while keeping repository checks and source ownership outside the overlay's
  contents.

### Why / context

- Machine-specific shell integration must remain separate from the public
  repository without making the loader depend on one physical checkout layout.

### Evidence

- PR #90 added the symlink-aware boundary; PR #91 moved only the overlay
  pointer to its current owner without importing private content.
